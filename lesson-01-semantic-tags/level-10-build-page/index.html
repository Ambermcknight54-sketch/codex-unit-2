Semantic Foundations

Semantic HTML introduces meaning to the web page structure so that browsers, search engines, and screen readers can inherently interpret the layout hierarchy.

Key Structural Elements

A compliant layout separates document roles into these core components:

  • Header: Hosts introductory text, main titles, and global navigation links.
  • Main: Encapsulates the unique, central content specific to the page view.
  • Footer: Contains copyright details, privacy policy nodes, and secondary links.
