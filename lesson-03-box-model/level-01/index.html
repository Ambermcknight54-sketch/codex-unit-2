BOX MODEL

Every HTML element is treated as a rectangular box consisting of four layers. The "content" layer holds the actual text or images. Surrounding that is the "padding", which clears space directly around the content. Next is the "border", wrapping around both the padding and content. Finally, the "margin" is the outermost layer that creates empty space around border box.
